# ITanakh — inguqulelo yesiXhosa (selah-xh)

Le yinguqulelo yesiXhosa yeZibhalo eziNgcwele zesiHebhere (iTanakh).
Indinyana nganye ikwifayile yayo, kwaye ithokheni nganye ibotshelelwe
kwigama layo lesiHebhere.

**Ukubhala: oonobumba besiLatin.** Ulwimi sisiXhosa esibhaliweyo
esisemgangathweni.

## IsiHebhere — kuqala

Le nguqulelo ikho ukuze ikukhokelele kwisiHebhere — hayi ukuthatha
indawo yaso. Oko kufundwa rhoqo sisiHebhere: oonobumba baso, izandi zaso,
iimpawu zaso. Umbhalo wesiXhosa yifestile, hayi isibambeli. Apho
zohlukana khona, inyaniso ikwisiHebhere.

## Ubume beefayile

```
<incwadi>/<isahluko>/<indinyana>.json
```

Amagama eencwadi kwiifolda abhalwe ngesiNgesi: `genesis/1/1.json`,
`psalms/33/12.json`.

Ifayile nganye:

```json
{
  "translation": "indinyana ifundwa iphela",
  "tokens": [{"surface": "igama lesiHebhere", "gloss": "inkcazelo yesiXhosa"}]
}
```

`surface` — **umphezulu**, irekhodi yesiHebhere. Asingowethu ukuwubhala;
usuka kumbhalo wesiseko, kwaye awutshintshwa.

`gloss` — **inkcazelo** yesiXhosa yale thokheni yesiHebhere kanye.
Inani leenkcazelo lilingana nenani lamagama esiHebhere. Rhoqo.

`translation` — **inguqulelo**: indinyana enye ifundwa kwimeko yayo,
ukuze ifundeke ngokuvakalayo.

`marks` — kwithokheni ye-⟨את⟩ kuphela: igama lesiXhosa elikhonjwa
luphawu.

## Oko kuthethwa zizibiyeli ⟨ ⟩

Izibiyeli ezinamakona zisetyenziselwa izinto ezimbini, kwaye
kubalulekile ukuzahlula.

**1 · ⟨את⟩ — uphawu lwesiHebhere olungaguqulelwayo.** KwisiHebhere,
u-אֵת ligama elincinci elime phambi kwento eyenzelwa sisenzi. IsiXhosa
asinalo igama elilinganayo, kwaye iinguqulelo ezininzi ziyalishiya
ngokuthula. Thina siyaligcina, libhalwe njengoko libhaliwe — liyinxalenye
yolwakhiwo lwesiHebhere. Ayisiyompazamo yoshicilelo; ligama elikhoyo
embhalweni. Uphawu lunosapho: i-את ngamanye amaxesha iza nezakhi
ezincamathelayo (ואת, אתו, אתם) — zonke zezalo elinye.

**2 · ⟨igama⟩ — isiXhosa esingekho kwisiHebhere.** Apho isivakalisi
sesiXhosa sifuna igama elingekho kwisiHebhere ukuze sime, elo gama
libekwa phakathi kwezibiyeli. Izibiyeli zithi: *eli gama longezwe
ngumguquleli; alikho kwisiHebhere.*

**Ngaphakathi kwezibiyeli akukho lwimi lwasemzini.** Kukho isiXhosa
okanye uphawu lwesiHebhere — akukho lwesithathu.

## IGama

IGama **aliguqulelwa, libhalwa ngokwesandi**.

| isiHebhere | apha | oko sikwalileyo |
|---|---|---|
| יהוה | **uYahwe** | **uYehova**, **iNkosi**, **uThixo** endaweni yeGama, **uMdali** |
| אלהים | **uElohim** | **uThixo** endaweni yeGama |
| אל | **u-El** | *uthixo* endaweni yeGama |
| אלוה | **u-Eloha** | — |
| אדני | **u-Adonayi** | **iNkosi**, **iNkosi uThixo** |
| שדי | **uShadayi** | **uSomandla** yedwa |
| יה | **uYah** | — |
| צבאות | **Tsebhayoti** | "wemikhosi" |
| שאול | **iSheol** | "isihogo" |

**UYehova neNkosi zimi kwiiBhayibhile zesiXhosa kangangexesha elide.**
Nangona kunjalo, azikho apha. INkosi yinguqulelo *yesibizo sewonga*,
hayi yeGama; uYehova luhlobo oluxubileyo. Apho umbhalo uthi יהוה, zombini
zifihla iGama. Oko akuthethi ukuba sisiXhosa esibi — kuthetha ukuba
zime *endaweni yeGama*, hayi iGama ngokwalo. Ofuna ukuva isithethe
uya kusifumana kwezinye iiBhayibhile zesiXhosa. Apha kume oko
kubhaliweyo.

**Isimaphambili u- sisigrama.** Isimaphambili sodidi 1a (uYahwe,
uElohim) nezivumelanisi — nguYahwe, kaYahwe, kuYahwe, noYahwe — ziyigrama
yesiXhosa, asikokutshintshwa kweGama. Isiqu sihlala siphelele. Into
engavumelekanga kukwaphula isiqu (*uYawe*) okanye ukutshintsha unobumba
waso (*uJahwe*).

## Uthixo nenkosi eziqhelekileyo zisemthethweni

Apho isiHebhere sithetha ngoothixo beentlanga okanye ngenkosi engumntu,
*uthixo*, *oothixo*, *inkosi* zime ngokufanelekileyo — oko akukokufihla
iGama, kukuguqulela. **Ithokheni yesiHebhere iyagqiba, hayi igama
lesiXhosa ngokwalo.** Ku-1 Kumkani 20:23 abase-Aram bathetha
ngoothixo bawo; **oothixo** bume apho ngokufanelekileyo.

## Amagama aphawuliweyo

- **ikhesedi** (חֶסֶד) — uthando lomnqophiso olungapheliyo. Hayi
  "ubabalo" nje, hayi "inceba" nje. Alikho igama elinye lesiXhosa
  elilithwalayo.
- **iSheol** (שְׁאוֹל) — indawo yabafileyo, njengoko isiHebhere sitsho.
  Hayi "isihogo".
- **uMashiya** (מָשִׁיחַ) — **othanjisiweyo** — kwinqanaba leTanakh,
  akaze abe "nguKristu".
- **iTora** (תּוֹרָה) — umyalelo, imfundiso. **ברית** —
  **umnqophiso**.
- **inefeshi**, **iruwakh**, **ikhavodi** — ngokwendawo yawo
  (umphefumlo okanye ubomi; umoya; uzuko okanye ubunzima) —
  akabotshelelwa kwigama elinye.

Amagama abantu neendawo alandela uhlobo lwesiHebhere: **u-Avraham**,
**uMoshe**, **uYehoshuwa**, **uShawuli**, **uParo**, **iMitsrayim**,
**iYerushalayimi**.

## Indinyana ekukhanyeni kwayo

Indinyana nganye ithetha oko ikuthethayo kwindawo yayo — siyifunda
kwinkolo yesiHebhere yokuba uElohim mnye (Duteronomi 6:4). Asiyitsali
imfundiso yamva ibuyele emva; asifundi isiphelo sebali ekuqaleni kwalo.
Umguquleli unika oko kubhaliweyo — kungekho ngaphezulu, kungekho
ngaphantsi.

## Imeko

Iincwadi zonke zeTanakh. Isiseko sesiHebhere yi-OSHB / WLC 4.20.

Esi sisihlandlo **sokuqala** sokuguqulela. Asililo ilizwi lokugqibela;
linqina. Lifunde ecaleni kwesiHebhere.
